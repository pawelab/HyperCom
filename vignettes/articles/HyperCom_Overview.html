Load in example data

HyperCom requires three inputs:

  1. A gene x cell matrix with genes as row names and cells as column names

  2. A dataframe of cell metadata containing sample and optionally group columns which need to be specified as variables

  3. A dataframe of ligand-receptor (LR) interactions. HyperCom contains 2 built in LR databases formatted properly:

    • CellChat human cellchat.hs.lrdb

    • CellChat mouse cellchat.mm.lrdb

In this vignette we will use a 1000 cell subset of heart failure from Alexanian et al, 2021. This example subset is included in the package as alexanian2021.counts and alexanian2021.metadata.

Running HyperCom

The standard pipeline can be run using the HyperCom or for a Seurat object the HyperCom_seurat function. Both write every step to outdir and return the results as a list. This vignette details each component function of the pipeline.

res <- HyperCom(lrdb=cellchat.mm.lrdb, counts=alexanian2021.counts,
                metadata=alexanian2021.metadata, sample="sample",
                group="condition", keep=NULL,
                significance=FALSE, parallel=FALSE, outdir="overview")
head(res$priority[["1"]])

res <- HyperCom_seurat(seurat=seurat_object, lrdb=cellchat.mm.lrdb, sample="sample",
                       assay="RNA", layer="counts",
                       group="condition", keep=NULL,
                       significance=FALSE, parallel=FALSE, outdir="overview")

Preprocessing

In order to reduce memory usage, we first filter the counts matrix to only genes present in the LR interactions with expression greater than 0. The function also transposes the matrix. For a Seurat object, HyperCom_seurat reads the counts layer and the cell metadata and runs every step.

lr.counts <- filter_counts(counts=counts, lrdb=lrdb, outfile=NULL)
dim(lr.counts)
[1] 1000  663

Next we filter the ligand receptor interactions to only interactions where all genes are present in the filtered expression matrix.

lrs <- generate_lrs_table(counts=lr.counts, lrdb=lrdb, outfile=NULL)
dim(lrs)
[1] 1042    5

Generating Hypergraph

To generate the hyperedges, which are edges that contain multiple nodes, we use the expression matrix and the LR interactions to create 2 types of hyperedges:

  1. expression edges - edges containing a ligand or receptor gene and the cells that express it

  2. interaction edges - edges containing the genes that comprise an LR interaction

HyperCom represents these hyperedges as a dataframe with an edge and node column where the node belongs to the edge. The weight is set to 1 for each edge.

hyperedges <- generate_hyperedges(counts=lr.counts, lrs=lrs, outfile=NULL)
head(hyperedges, 2)
# A tibble: 2 × 3
  edge                node   weight
  <chr>               <chr>   <dbl>
1 TGFB1_TGFBR1_TGFBR2 Tgfb1       1
2 TGFB1_TGFBR1_TGFBR2 Tgfbr1      1

We can represent this hypergraph as an adjacency matrix where the nodes are the cells, ligand genes, and receptor genes. Each entry is the number of hyperedges shared by nodes. The matrix is not stored: adj keeps which nodes are in which hyperedge, which is much smaller, and works like a matrix (dim(adj), adj[i, j], as.matrix(adj) for the whole matrix).

adj <- generate_adjacency_matrix(hyperedges=hyperedges, outfile=NULL)
dim(adj)
[1] 1663 1663

Calculating Network Connectivity

In order to calculate the network connectivity of the hypergraph we perform a random walk on the adjacency matrix to produce an influence matrix. By default the whole influence matrix is never made, so its memory grows with the number of cells instead of its square (on this small example both are about 20 MB; data with at least as many hyperedges as nodes get the whole matrix); infMat[i, j] gives entries and as.matrix(infMat) the whole matrix. method="lu" makes the whole matrix exactly as HyperCom 0.0.0.9000 did.

infMat <- generate_infMat(adj=adj, outfile=NULL)
dim(infMat)
[1] 1663 1663

Preparing Metadata

To account for genes now being present in the matrices, we then process the metadata to contain information on the genes as well as cell metadata. Additionally to reduce memory, we reduce the number of columns to just cell, sample, and group. Optionally other metadata columns can be kept.

Downstream Analysis

Identifying Important LR Pairs

We can also identify important LR pairs by using HyperCom scoring on LR pairs. This prioritization scores LR pairs to find highly communicative LR pairs that are optionally group specific. The weights arg sets how much the fraction of cells expressing a pair’s genes counts in the priority: 1 (the default) weighs it like the other terms of the score and smaller values favor pairs specific to fewer cells; a vector of weights gives one result each. A p-value can be calculated for each LR pair against 1000 random gene interactions, which takes about four times as long. By default the significance arg is FALSE; the seed arg makes the p-values reproducible. The prioritize_lr function runs on one thread by default; parallel=TRUE uses one thread per physical core and the threads arg sets the number directly.

priority <- prioritize_lr(lrs=lrs, adj=adj, infMat=infMat, metadata=metadata,
                          weights=c(1), significance=FALSE, parallel=TRUE,
                          outdir=NULL)
